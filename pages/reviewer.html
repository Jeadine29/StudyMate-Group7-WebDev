01 · INTRODUCTION

What is HTML?

HTML stands for HyperText Markup Language. It structures content on web pages.

02 · ELEMENTS

HTML Elements

An element usually has an opening tag, content, and a closing tag. Some elements, such as images, do not need closing tags.
